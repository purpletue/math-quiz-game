# A math quiz game i made in a week to learn javascript
So h1 basically explains it. i made this project to learn javascript and how to integrate it into web design. All files are included here, so html, css, javascript, and the background. just a disclaimer, this is absolute ass. it's a simple procedurally generated math quiz. that's it. nothing more, nothing less. exactly what it says on the tin. 
## Features
- addition, subtraction, multiplication, division, modulo, powers, solve for X, 3 number equations.
- a UI that sure as fuck exists
- it knows your name but doesn't do much with it
- thats pretty much it.
## Publishing
This project is published as a [website](https://math-quiz-game-eta.vercel.app) and an [android application](https://github.com/purpletue/math-quiz-game/releases). the android app does not have ads nor ask for any permissions.
## AI usage declaration
i used no ai in the coding of this project, but i used it as a way to learn javascript.
## App installation instructions
This game is an **android** app. it does **NOT** work on iOS or any operating system other than android. to install it, download the APK file from the releases page, linked above. then just open the file. the android app installer will guide you through the rest of the process. this is sideloading so it might not work if Google continues being assholes, but as of October 2026 it works. I will try to publish it on Google play, and when I do it'll be linked in this page. to open this app, simply find it in your launcher. it's a normal android app.
